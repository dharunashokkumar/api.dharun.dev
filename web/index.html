Free logo API

Ticker to logo URL

Put a ticker in the URL and get the logo back as SVG or PNG. No API key. Use the form to resolve a symbol and copy an embed URL for your app.

GET v1/logo/{symbol} accepts TCS, NSE:TCS, TCS.NS or an ISIN. Add ?format=png&size=128 for PNG, or ?fallback=monogram for a placeholder when a symbol is unknown.

Company data: v1/companies/{symbol}. Search: v1/search?q=. Docs: llms.txt, OpenAPI. AI agents can connect to the MCP server at mcp.
