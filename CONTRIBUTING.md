# Contributing

Thank you for wanting to help. This project takes **issues, not pull requests**: every line
of code here is written by the maintainer, which keeps the licensing simple. Pull requests
are closed without review, however good they are.

What helps most:

- **Wrong or missing data.** A pincode with the wrong district, a missing IFSC, a holiday
  on the wrong date: open an issue with the request you made, what it returned and where
  the correct value is published.
- **Bugs.** The request, the response and what you expected.
- **New APIs.** What you need, and where the data could come from. A source that may
  legally be redistributed, with a clear licence, makes it much more likely to be built.
  [`ROADMAP.md`](ROADMAP.md) lists what is planned and what was turned down, and why.
- **Security problems.** Not as an issue: see [SECURITY.md](SECURITY.md).

Questions about using the API are welcome too. The documentation is at
[api.dharun.dev](https://api.dharun.dev).

By opening an issue you agree that ideas and data corrections in it may be used in the
project.
